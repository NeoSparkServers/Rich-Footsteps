verified to be byte-identical to the pinned tag by SHA-256 comparison of
all 1,090 files under upstream's `src/` directory.

### Included upstream-origin material, and where it comes from

Paths below refer to the pinned upstream tag.

- `sounds/*.ogg` (455 files): OGG sound assets taken from upstream's
  `src/main/resources/assets/presencefootstepsmono/sounds/` tree — the
  mono sound set that upstream ships alongside its stereo set. All 455
  upstream mono assets are bundled: 439 are byte-identical copies,
  renamed from `<acoustic>/<name>.ogg` to
  `presence_footsteps_<acoustic>_<name>.ogg` for Luanti positional
  playback; the 16 water files
  (`presence_footsteps_water_stereofix_water_*.ogg`) are lossy re-encodes
  of the corresponding upstream mono `water/*.ogg` files, renamed the
  same way. No asset from the stereo
  `src/main/resources/assets/presencefootsteps/sounds/` tree is bundled.
- `data/sounds.lua`: generated from the pinned tag's
  `presencefootstepsmono/sounds.json`.
- `data/acoustics.lua`: generated from the pinned tag's
  `presencefootsteps/config/acoustics/*.json` (82 JSON files).
- `data/block_map.lua`: generated from the pinned tag's
  `presencefootsteps/config/blockmap.json`.
- `data/primitive_map.lua`: generated from the pinned tag's
  `presencefootsteps/config/primitivemap.json`.
- `data/golem_map.lua`: generated from the pinned tag's
  `presencefootsteps/config/golemmap.json`, extended with Mineclonia and
  VoxeLibre entity-name aliases.
- `data/biome_variance.lua`: generated from the pinned tag's
  `presencefootsteps/config/biomevariancemap.json`, extended with extra
  Luanti biome entries.
- `data/entity_locomotion.lua`: the pinned tag's
  `presencefootsteps/config/locomotionmap.json`, remapped from
  `minecraft:*` entity IDs to Luanti entity names (`mobs_mc:*` and
  similar) while preserving the upstream locomotion classes.

Each generated Lua file names its upstream source in a header comment.
The conversion scripts live in this repository's history.
